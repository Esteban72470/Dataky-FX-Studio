ROBLOX STUDIO

Connecter le moteur de rendu

Pour l’aperçu intégré : lancez INSTALLER_LE_PONT.bat, redémarrez Studio, puis cliquez sur Plugins → Dataky FX → Connexion. Le bouton Aperçu demandera votre autorisation de capture. La commande ci-dessous reste disponible pour éditer temporairement sans installer le pont.

  1. Ouvrez un projet dans Roblox Studio, en mode édition.
  2. Affichez la barre de commande dans Studio, puis collez la commande ci-dessous.
  3. Revenez ici pour appliquer et lire votre effet. Le pont reste local sur votre ordinateur.
